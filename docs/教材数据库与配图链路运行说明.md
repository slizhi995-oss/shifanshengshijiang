# 教材数据库与配图链路运行说明

更新：2026-10-12。

## 现在的操作流程

1. 重启后端加载新增路由和数据表，刷新前端。数据库初始化会创建新增表，不清空现有数据。
2. 管理员进入“教材与图片素材”，统一上传 PDF，填写教材名称、学科、年级、出版社、版本和册次。文件上限 80MB，最多 1,000 页，不接收加密 PDF；同一文件 SHA 去重。
3. 对照原教材核对章节标题、PDF 页序号、印刷页码和正文。已有 PDF 书签只作为章节草稿，未经核对不会开放给用户。没有书签时手工新增章节，按页码读取正文。
4. 可选的管理员素材整理：核对图片候选的实图、图号、标签、内容说明、用途/条件和关联章节，再勾选已核对。需要人工补充时，从原页裁好后通过“补充教材裁图”上传并核对；用户生成教案不必等待逐张人工整理。
5. 师范生在“AI 教案生成”选择“教材生成”，填写学科、年级、课题，选择教材并请求推荐章节，最后确认章节；确认前不能生成。
6. 点击生成后，先完成章节图片提取，再生成教案正文。程序按确认章节的 PDF 页范围渲染原页，让启用的默认视觉模型定位完整插图（含矢量示意图、子图、标签和图注），从原页裁取实际像素，再对裁图完整性、教材原文依据和对象关系进行视觉核对。通过的图片自动登记到该章节，不需管理员逐张预先导入；提图结束后重新读取章节正文和最新图片资料，用教材内容及图片说明设计教案，再按教案图片需求匹配素材，生成带图片链接的 Markdown 和教材来源。提图期间章节被修改时停止生成，提示重新生成。
7. 页面自动显示教材图片。普通 Markdown 下载保留受保护的应用图片链接；“下载教案及图片”提供 ZIP，含 `教案.md`、`教材依据.json` 和 `images/`，图片路径可在离线 Markdown 中使用。

通用教案仍可由用户明确切换使用，不会在教材不可用时静默回退。

## 当前教材样本

源文件：项目根目录 `物理必修第一册.pdf`，134 页，有文字层。数据库保存 134 页正文、103 张原生图片候选。

2026-10-12 已补齐物理必修第一册的完整目录：4 章、19 个教学小节，连同各章概述、复习与提高、序言及学习资源共 32 个已发布条目，可在前端“物理 → 高中一年级 → 教材生成”中选择。章节正文来自已入库的 PDF 页文本，PDF 页序号为印刷页码加 5；各小节边界已对照目录及起始页标题检查。

第四章“牛顿第一定律”保留原章节 ID，PDF 第 88–92 页，对应印刷页 83–87。第 93 页是下一小节，不纳入当前检索。其他章节首次生成时会自动提取及核对图片；已核对的同页、同图号素材优先复用。

在 `backend` 目录运行 `.venv\Scripts\python.exe -m scripts.publish_physics_chapters` 可重建相同目录。脚本限定当前 PDF 的 SHA，保留已有章节 ID 及图片关联；写入前将 SQLite 数据库备份到 `outputs/physics-chapters/`。

原人工核对图片：滑冰运动员、图 4.1-1 伽利略斜面实验频闪照片、牛顿肖像、图 4.1-2 小钢球与纸片。原始提取文件仍在项目根目录 `必修第一册图片/`。自动提图通过视觉核对的素材会在适用条件中标注“自动提取及视觉核对”和教材原文依据；其余未核对候选仍不用于自动生成。

出版社为人民教育出版社，精确版次仍标记待核对，以当前 PDF 的 SHA 区分实际文件版本。换一本文件不会复用旧版本的图片关联。

本地样本幂等导入：在 `backend` 目录执行：

```powershell
.venv\Scripts\python.exe -m scripts.import_physics_textbook --pdf ../物理必修第一册.pdf --manifest ../必修第一册图片/图片清单.json
```

## 存储和接口

新增表：`textbooks`、`textbook_pages`、`textbook_chapters`、`textbook_assets`、`textbook_lessons`。PDF/PNG 存储于 `TEXTBOOK_STORAGE_DIR`，本地默认 `backend/private_textbooks/`；Docker 使用 `/app/private_textbooks` 与 `textbooks_data` 数据卷。备份和迁移必须同时保留数据库及该私有目录，目录未入 Git。

所有接口前缀 `/api/v1`，都需要登录：

| 接口 | 用途 |
| --- | --- |
| `GET /textbooks` | 按学科、年级列出教材，普通用户只能看到已发布教材 |
| `POST /textbooks` | 管理员上传 PDF 并解析 |
| `PATCH /textbooks/{book}` | 管理员核对并修改教材元数据 |
| `GET /textbooks/recommend` | 推荐已发布章节，不自动替用户确认 |
| `GET /textbooks/{book}/chapters` | 查看该教材章节 |
| `POST /textbooks/{book}/chapters`、`PUT /textbooks/chapters/{id}` | 管理员核对与发布章节正文 |
| `GET /textbooks/{book}/assets` | 管理员查看原图候选，可按 PDF 页范围过滤 |
| `POST /textbooks/{book}/assets` | 管理员补充教材裁图，默认未核对 |
| `PATCH /textbooks/assets/{id}` | 管理员标注标签、条件和章节，核对图片 |
| `GET /textbooks/assets/{id}/image` | 登录读图；普通用户仅可读取已发布章节的已核对图片 |
| `GET /textbooks/{book}/pdf` | 按教材可见性读取私有 PDF |
| `GET /textbooks/lessons/{id}/bundle` | 教案所有者下载 Markdown 及图片 |

`POST /ai/generate` 新增 `use_textbook` 与 `textbook_chapter_id`。旧客户端默认通用教案，保持接口兼容。教材模式需章节且学科/年级一致，否则在调用模型前返回 422；教材模式暂时不支持流式响应。

规范图片引用：`![图注](/api/v1/textbooks/assets/tb-<32位id>/image)`。教材教案引用必须通过章节范围核验；不能插入外部图片地址、其他章节草稿或模型虚构的素材 ID。

## 当前边界

2026-10-17 配图修复：

- 数学 PDF 中的全角数字、私有字体句点/连字符和 OCR 横线统一用于图号比对；例如 `图６．２\ue011２` 与 `图6.2-2` 对应同一素材，不再把它截成 `图6.2`。
- 原页定位提示包含程序读取的真实图注和坐标；小型矢量几何图仍按原页像素提取。裁图包含下方图注，并清理边缘误带入的相邻段落；裁图复核同时提供原始整页和实际裁图。
- 单图元数据不合格不再丢弃同页全部有效图片。拒绝、漏提或部分失败的页不会写成完成缓存，保留成功结果并继续重试；缓存记录 `page_issues`，提图策略版本升为 5，使旧错误结果失效。短的真实练习题图注（如“第3题”）也可作为原页证据。
- 原图完整而说明误读时，视觉复核可更正标题、描述和条件；不能改动图片、图号、范围或原文依据，不完整或无法核对的图仍拒绝。
- 图片检索同时提供同章图号候选和对象描述候选，仍由选择器核对用途和条件。生成时仅使用实际素材清单，避免虚构图号、把示意图称为实景照片或要求不存在的图片。
- 当前原生百炼 Qwen3-VL-Plus/Flash 提图和复核启用官方 JSON Object 模式，避免非法 JSON 使整页失败；代理或未声明支持的模型不注入该参数。[官方接口说明](https://www.alibabacloud.com/help/en/model-studio/qwen-structured-output)。

真实验证：初中数学七年级上册“6.2 直线、射线、线段”6 页完成提图，图6.2-1至图6.2-16均可检索；高中数学“基本不等式”的图2.2-1补提成功。使用实际文本模型重生成前者，得到 10 处教材图片、0 个“图片待插入”，生成的 Word 也有 10 个内嵌图片对象。原始教案历史保持原样，旧结果需重新生成才能采用新素材。

诊断命令（backend 目录，会使用当前配置的模型并记录正常调用量）：`python -m scripts.verify_figure_recovery --chapter-id <章节ID>`；增加 `--page <PDF页序号>` 只核对单页，增加 `--generate` 用当前可用素材真实生成教案和 Word。回复、状态和样本位于 `outputs/image-recovery/`，不包含接口凭据。

- 首版是确认章节后的整节正文检索，以及同章节图片的图号/标签/描述检索，不是向量检索。超过 48,000 字符的小节需先拆分；以后跨章节检索再引入嵌入模型和向量索引。
- 没有自动 OCR，也不会从扫描整页推测出已核对教材正文。管理员须补充并核对文本；只有页码标记的空白内容无法发布。
- 上传 PDF 时提取内嵌图片候选；生成教案时额外按章节自动定位、裁取及视觉核对完整图，包括矢量图。原页定位和裁图核对均须成功，范围、原文证据、图号或完整性不合格的图不会自动登记。管理员仍可补充裁图或撤回图片核对状态，自动流程不会覆盖撤回。
- 自动提图需启用可用的视觉模型。单页遇到临时超时或响应格式错误会自动重试一次；模型不可用、整章超时或重试后仍有部分页失败时，提图步骤返回后按已核对可用素材生成正文，并在页面提示配图未完成；不会只凭文字把未核对候选当作可用图。单次视觉调用限时 90 秒，整章提图限时 300 秒，最多同时处理 3 页；提图使用独立数据库会话写入素材，正文生成须等待提图结束并重新读取图片资料。前端及反向代理的教材生成请求上限为 660 秒。
- 自动提图缓存位于教材私有目录的 `auto-chapters/{章节ID}/`。缓存绑定 PDF SHA、章节正文与页范围、视觉模型配置和提取策略版本，并核验素材字节及核对状态；同章节重新生成复用有效结果。已完成页可在部分失败时先保留，重新生成仅重试未完成页；失败结论不作为有效缓存。目录中的 JSON 保存裁图页码、范围和教材原文依据。
- 模型提出图片需求后，程序负责检索和验证引用。图号命中只限定候选，仍由模型检查教案用途与物理条件；匹配不到留具体图片占位，不用相似图凑数。匹配回复漏项或无效时最多重试一次，每次限时 45 秒；仍失败则保留教案正文及素材占位，返回配图待补充提示，不丢弃已生成的教案。文本模型偶尔输出外部地址、其他章节素材编号或超过 16 处图片需求时，也会转为章节内检索或可编辑占位，不再让整份教案生成失败。
- 教案下载只打包教材原图。
- 生成结果是教案初稿，教材解析公式和教学内容仍可人工核对。
