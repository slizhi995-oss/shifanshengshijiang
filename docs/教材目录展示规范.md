# 教材目录展示规范

所有科目共用同一套目录间距，不再叠加各科独立的 padding 与条目内部缩进。桌面端左、右边距均为 20px，每深入一个层级增加 40px：单元/章标题 20px，直属条目或栏目 60px，栏目下的内容或子篇目 100px。无分组标题的平级目录从 20px 开始。视口宽度不超过 600px 时，边距改为 16px、层级缩进改为 24px，减少窄屏的横向占用。

缩进依据实际显示的分组、栏目及嵌套关系计算。物理目录中标记为 nested 的直属小节只缩进一级，避免同时累计章分组与 nested 标记。高中语文的课次编号列宽使用同一个层级间距，同课后续篇目因此与课题文字对齐。小学语文数字与课题之间的两个中文全角空格继续保留。

可选条目采用 24px 行高、42px 最小行高，长标题自动增高和换行；编号列与课题文字分开时，换行仍对齐课题起点。下拉框与选择框等宽，始终在输入框上方或下方展开，不因长标题向侧面偏移。高度限制随视口调整，内容过多时纵向滚动。单元之间使用统一的细分隔线与留白，悬停和选中采用浅色背景，选中项以蓝色文字和左侧细线提示，保持普通字重。

通用间距调整不改各科目录条目的顺序、可选状态、数据库 ID、正文和页码。英语目录自 2026-10-22 起采用下述两级结构。

初中英语目录展示为“单元完整标题（含主题问题）→ Section A / Section B（含原有问题）”。A/B 本身是可选章节，听、说、读、写、语音、语法等任务合并到对应板块的正文，目录不再展示任务细项和独立 Project。高中英语展示为“单元 → 原有栏目”，Listening、Speaking、Reading、Writing、Pronunciation、Structure、Project、Video Time 等栏目各自成为可选章节；WORKBOOK 继续保留单独分组。两类目录均只缩进一级，使用普通字重，取消重复的栏目标题行。

数据库保留原任务记录、历史教案和图片引用，将旧任务撤销发布，新增板块记录。正文按审定的来源页集合合并并去重；非连续页码明确写为 `14-15, 18-19, 74`，正文和自动提图只读取这些页，不把中间无关页面混入。旧单元/任务的配图可由相应来源页的板块继续使用。已审定的 5 册初中、7 册高中教材共 350 个板块，导入和缓存重读也采用同样规则。

在 backend 目录运行 `python -m scripts.merge_english_sections` 预览，添加 `--apply` 才会写入，并在 `outputs/english-sections/` 自动备份 SQLite 数据库。`python -m scripts.verify_english_sections` 核对学生接口、来源正文和生成入口，并导出页面检查数据；项目根目录运行 `node scripts/verify_english_sections_ui.cjs` 验证桌面与移动端选择器。

检查包括既有的 `node scripts/verify_textbook_choices.cjs`、前端类型与构建，以及真实教材数据的页面核对。页面检查覆盖 26 个跨科目、跨学段样例，分别在 620px 和 340px 面板上执行，共 52 组；核对层级缩进、行高、框体对齐及文字横向溢出。结果位于 `outputs/chapter-layout-verification.json`。
