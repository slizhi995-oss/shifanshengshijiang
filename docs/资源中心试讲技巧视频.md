# 资源中心试讲技巧视频

管理员入口：侧边栏「试讲技巧视频」（`/admin/teaching-tips`）。添加 B 站完整视频链接后，可点击「读取标题与封面」，也可手动填写标题、分类、简介。封面可以留空，前台会使用默认封面。B 站短链接需先打开，复制包含 BV 号的完整链接。

新视频默认下架，编辑时开启「上架」并保存即可对学生展示。排序数字越小越靠前；同一排序按最新添加优先。相同 BV 号的不同分集可分别配置，同一分集不能重复添加。

AI 资源中心集中展示管理员上架的精选试讲技巧视频，分类、分页和原站跳转保持可用。这里不再展示根据某份教案匹配的音频或教学视频。

教案配套资源移到「AI 教案生成」的结果页，在 Word 教案下方直接展示；顶部「配套资源」按钮可滚动定位。生成完成后自动读取配套音频，并复用后台视频检索与轮询，结果返回后自动出现，无需刷新。没有音频、视频候选或已保存视频时隐藏整个区域，不展示通用推荐、空状态或后台检索错误提示。后台仍在检索时继续等待，切换教案或离开页面后取消旧页面轮询。

资源中心的「历史记录」会打开生成页中的对应教案。旧 `/student/resources?resourceLesson=...` 和 `?lesson=...` 链接自动转到生成页。服务端历史正文只通过校验归属后的详情接口返回，恢复到当前用户的本地教案历史；不重复生成教案。

数据存储在新增的 `teaching_tip_videos` 表中，后端启动时通过现有 `Base.metadata.create_all` 自动建表。接口沿用登录认证：`/resources/teaching-tips` 仅返回上架内容；`/admin/teaching-tips` 下的读写及元数据接口仅管理员可用。

验证命令：

```powershell
cd backend
.\.venv\Scripts\python.exe -m pytest tests/test_teaching_tips.py tests/test_lesson_videos.py -q
cd ../frontend
npm run build
```

启动前端开发服务（默认端口 5173，可通过 `VIDEO_UI_URL` 指定其他地址）后，在仓库根目录执行 `node scripts/verify_teaching_tips_ui.cjs`，使用独立测试数据验证桌面和手机布局、卡片跳转、分类筛选、错误重试，以及管理员添加、读取元数据、下架和删除流程。`node scripts/verify_generator_resources_ui.cjs` 验证生成页的自动检索、轮询回显、音频试听下载、无结果隐藏、历史恢复和旧链接兼容。测试数据不会写入实际数据库。
