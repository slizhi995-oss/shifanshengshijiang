# 全学段教材批量导入

2026-10-15。

教材选择使用固定十科：语文、数学、英语、物理、政治、道德与法治、化学、生物、地理、历史。选择顺序为科目、学段（小学/初中/高中）、教材、章节。教材展示名取文件名移除学段、科目和 `.pdf` 后的剩余部分，不改写册次、数字或括号。道德与法治按文件名识别，不按其所在的“政治”目录归类。

## 导入和存储

在 `backend` 目录运行：

```powershell
.venv\Scripts\python.exe -m scripts.import_textbook_library --source ../教材
.venv\Scripts\python.exe -m scripts.import_textbook_library --source ../教材 --apply
```

第一条只解析并输出报告，第二条写入当前配置的 SQLite 数据库。写入前使用 SQLite backup API 备份数据库。报告、备份、按 SHA 缓存的解析结果位于 `backend/outputs/textbook-library/`；正式结果是 `import-report.json`，其中记录每本教材的文件名、SHA、数据库 ID、页数、文字页数、发布章节数和问题。

源 PDF 不变，私有副本保存到 `TEXTBOOK_STORAGE_DIR/library/{sha256}/original.pdf`；数据库保存教材元数据、逐页正文和章节页范围。备份/迁移需同时保留数据库和私有文件目录。批量导入不预先裁取整库图片；选中章节生成教案时，复用现有按章节提图及视觉核对流程。

同批文件 SHA 重复时，写入前终止并列出冲突文件名。重复执行按 SHA 复用教材，保留既有教材、章节、配图、历史教案的 ID 和已发布正文。前端教材列表传 `catalog_only=true`，只展示符合本次文件命名规则的教材；历史记录仍可通过原 ID 读取，管理员列表仍可看到原教材。

## 章节解析边界

按 PDF 内容页的文字坐标配对标题和印刷页码，支持双栏目录、英语 Units 表格、全角数字，以及被 PDF 错合并到同一行的不同基线文字。通过正文标题和印刷页脚推断 PDF 页码偏移。只有正文标题可对应、正文充足且不超过 48,000 字符的条目发布；无法对应的条目保留草稿，防止相邻章节吞并它们的页范围。“古诗三首”等组合课文保留整体范围，不被其内嵌诗目切断。

常规导入不自动执行 OCR；文字不足标记 `needs_ocr`。无可用章节的文本教材标记 `needs_chapters`。这些教材仍可列出和查看 PDF，章节整理/正文识别完成后才能生成。管理员可在“教材与图片素材”核对和补充章节；机器解析结果仍应结合原教材核对。

2026-10-17 补充扫描件维护流程：`scripts.repair_scanned_textbooks` 对尚无章节的扫描教材做本地 OCR，逐页 JSON 按原 PDF SHA 缓存，不改写源文件。可安装 `requirements-ocr.txt` 使用跨平台 OCR，Windows 也可先运行 `--prepare-windows`，再使用根目录 `scripts/windows_textbook_ocr.ps1` 处理生成的任务清单，最后执行 `--apply`。写入前自动备份 SQLite，已有章节的教材不替换。扫描正文明确标注 OCR；公式、单位和单词仍需对照原 PDF。

已按原始目录逐项核对这 7 本扫描教材，目录记录和校验 SHA 位于 `scripts/scanned_textbook_contents.py`。记录的是印刷页码，PDF 偏移另行核对；多个正文标题校验通过后才采用人工核对的目录边界，避免重复页眉导致章节起点漂移。英语 Workbook 尾部过长条目保留草稿，不把附录合并进最后一个教学单元。修复报告与数据库备份位于 `outputs/scanned-textbook-repair/`。

## 接口兼容

`GET /textbooks` 新增 `stage` 和 `catalog_only` 筛选，响应新增 `stage`、`display_title`。原 `grade` 精确筛选保留；传小学/初中/高中则按学段查询。章节推荐和生成校验接受同学段教材，具体年级请求仍要求精确匹配，跨学段请求仍拒绝。

旧教案表单缓存中的具体年级转换为学段，当前目录内有效教材和章节可恢复选择。目录外的历史样本不列入新的教材选择，历史结果和图片仍按原 ID 读取。切换学段或科目清空原选择；切换教材只加载对应章节。教材/章节加载失败可重试，无可用章节不能生成。

教案生成页面仅显示当前科目适用的学段：语文/数学/英语为小学、初中、高中；物理/化学/生物/地理/历史为初中、高中；政治仅高中；道德与法治仅初中。切换科目时清理不适用的旧学段和教材。教材名称保持原文件名，排序按年级从低到高、上册/中册/下册、必修在前、选修（含选择性必修）在后；中文数字按数值比较。
