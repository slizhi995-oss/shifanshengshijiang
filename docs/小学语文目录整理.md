# 小学语文目录整理

范围为小学一年级至六年级上下册，共 12 册。目录不显示自动生成的“其他章节”分组标题；未分组的教学条目继续保留，例如一年级上册开头的“我是中国人”“我爱我们的祖国”“我是小学生”“我爱学语文”。有名称的单元分组保持原样。

显示时将课次数字（保留星号）与课题名之间统一为两个中文全角空格，例如 `1　　天地人`；下拉目录及选中后的名称均采用相同间距。数据库原始课题名、课题回填及正文引用不变。

移除独立的识字表、写字表、词语表、笔画名称表、常用偏旁名称表，以及“其他章节”占位记录。按完整标题匹配，避免误删“表里的生物”、识字单元、语文园地、口语交际、古诗词诵读和快乐读书吧等教学内容。仅限小学语文，不应用于初高中语文或其他科目。

实际 12 册共 35 项附表取消发布；保留原记录、章节 ID、正文页码及既有教案/配图引用。从目录、推荐、详情和生成入口统一排除，导入新 PDF 或读取旧解析缓存时使用相同规则，防止再次出现。前端同时隐藏无标题分组的占位标签并过滤附表。

在 `backend` 执行：

```powershell
.venv/Scripts/python.exe -m scripts.hide_primary_chinese_supplements
.venv/Scripts/python.exe -m scripts.hide_primary_chinese_supplements --apply
```

第一条预览，第二条先备份 SQLite 数据库再以事务取消发布条目；重复执行无新增变更。备份、恢复清单及核对报告位于 `backend/outputs/primary-chinese-directory/`。

测试覆盖小学全六个年级的附表过滤、保留教学标题、其他学段/科目不受影响、旧缓存导入、学生目录/推荐/详情、生成入口及管理员发布校验：

```powershell
.venv/Scripts/python.exe -m pytest tests/test_primary_chinese_directory.py tests/test_textbook_catalog.py tests/test_textbook_units.py -q -p no:cacheprovider --basetemp=outputs/pytest-primary-chinese-check
```
