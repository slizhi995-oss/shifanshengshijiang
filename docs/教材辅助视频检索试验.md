# 教材辅助视频检索试验

2026-10-22，在现有《课题2 氧气》（教案 37）与《第二节 熔化和凝固》（教案 38）上比较仅教案、教案加对应教材小节两种输入。两组沿用同一套 B 站搜索范围、最多 3 次搜索请求和最多 3 个结果的原始初筛规则。

## 实际观察

| 教案 | 仅教案 | 教案加教材 | 结论 |
| --- | --- | --- | --- |
| 氧气 | 4 个去重后有效视频链接，模型输出 3 条；一次硫燃烧搜索超时 | 5 个去重后有效视频链接，模型输出 3 条；3 次搜索完成 | 教材让需求细化到铁丝燃烧、硫在空气与氧气中的火焰对比，但两组调用成功情况不同，数量不能证明质量提升 |
| 熔化和凝固 | 0 个有效视频链接；一次图像检索请求失败 | 0 个有效视频链接；3 次搜索完成 | 实际执行的 3 条短语相同，补充教材没有改善本次召回 |

《氧气》的教材辅助版仍有误选：模型把“硫在氢氧化钠溶液中的歧化反应”放进输出列表，但理由里又写明应排除。该条不能算作匹配成功。这是原有初筛输出的问题，本次没有用关键词硬命中或评分门槛去掩盖它，也未把候选数当成有效推荐数。

《熔化和凝固》的三个短语是“海波熔化过程”“蜂蜡熔化特点”“温度-时间图像分析”。实际搜索响应返回 B 站专栏 `/read/…` 等页面，没有完整 `/video/BV…` 视频地址，因此在视频链接校验阶段归零，尚未进入 LLM 初筛。这说明本次空结果并不是更严格的教材匹配筛掉了视频，单靠增加教材上下文也未解决搜索返回页面类型的问题。

本次只有两份教案，且有服务超时，不能据此认定教材辅助已稳定提高召回或相关性；没有播放视频核验内容。

## 已实现的行为

- 自动检索读取教案明确绑定、已发布且学科年级相符的教材小节正文和已核对图注；不读取整本教材，不按课名猜版本。
- 教案决定用途，教材补充实验名称、对象和常用术语；不为教材中教案未采用的活动新增需求。
- 搜索仍限定 B 站视频，保留原来的宽松初筛。无有效教材时退回仅教案；手动关键词直接搜索原词。
- 正文、图注或教材关联变化会使自动检索缓存失效。页面标明本次采用的教材名称和小节，保留封面及点击标题跳转。
- 对照实验只保存独立报告，不覆盖现有教案内容和推荐缓存。已安装的新逻辑会在下一次正常检索时使用。

## 验证与复现

54 项相关后端测试通过；前端类型检查与生产构建通过；1440 和 390 像素宽度的界面检查通过，包括教材说明、封面、标题跳转、无底部操作栏、手动保存、移除及错误状态。

原始对照数据在 `backend/outputs/textbook-video-comparison/lesson-37.json`、`lesson-38.json`，包含需求、搜索响应、去重候选和模型输出。相同短语复用搜索响应，失败单独记录，未将超时冒充空结果。

从 backend 目录运行（会消耗真实服务额度）：

```powershell
.\.venv\Scripts\python.exe scripts/compare_textbook_video_search.py --lesson-id 37 --lesson-id 38 --output-dir outputs/textbook-video-comparison
```

同目录运行会复用已完成阶段；重新完整比较需使用新输出目录。
