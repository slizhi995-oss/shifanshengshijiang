# 高中英语目录

高中英语章节选择采用“单元 → 栏目 → 具体内容”。标题与内容统一使用普通字重，栏目相对单元向右缩进 40px，具体内容再缩进 40px。单元和栏目是分组标题，具体内容可选择并用于教案生成。必修册依原书顺序显示 Listening、Speaking、Reading、Writing、Pronunciation、Structure、Project、*Video Time；选择性必修册依原书顺序从 Reading 开始，没有独立 Pronunciation 栏时不添加空栏目。

练习册独立显示为 `WORKBOOK → Unit 1–5`，各 Unit 相对 WORKBOOK 缩进 40px，仍使用原有章节 ID、页范围和正文。删除整个 Appendices 目录，包括 Notes、Grammar、Words and Expressions in Each Unit、Vocabulary、Irregular Verbs；这些条目也不能通过章节详情或推荐接口重新选择。

目录数据见 `backend/app/data/highschool_english_directories.json`，以原始 PDF 的 SHA-256 绑定版本。目前覆盖七册、36 个单元、387 个具体条目。独立斜体听读策略提示（如 Predict content、Skim）不作为目录条目；语法名称内的术语和作品名称保留文字。空白单元格与斜线占位符不显示，Project 按示例不显示星号，*Video Time 保留星号。

每个条目的 `pages` 是纸质页码，文件级 `offset` 将其换算为 PDF 页码。目录中的第三篇 Reading 通常来自 Workbook，仍归入相应主单元的 Reading 栏。对于从听说页下半部分开始的阅读材料，页范围包含该起始页，避免丢失开头。条目正文直接取自已导入的教材页面，保留原有 OCR 识别提示。

既有教材库需从 `backend` 目录运行：

```powershell
.venv/Scripts/python.exe -m scripts.expand_highschool_english
.venv/Scripts/python.exe -m scripts.expand_highschool_english --apply
```

首条命令预览新增条目、来源页修正及移除的附录；第二条命令先通过 SQLite 在线备份保存完整数据库，再以事务新增或修正条目，并取消附录条目的发布。报告、备份与修复前字段保存在 `backend/outputs/highschool-english-directory/`。重复执行不会重复新增条目，已存在条目的 ID 保持不变。附录的历史数据库记录保留用于恢复和维护既有引用，目录中不再显示；原单元、Workbook、历史教案和配图引用均保留。

新导入和扫描版 OCR 修复流程也会补充这些条目。未经核对的 PDF 哈希继续采用原有目录流程，不套用其他版本的目录。

验证：

```powershell
.venv/Scripts/python.exe -m pytest tests/test_highschool_english_directory.py tests/test_textbook_units.py tests/test_textbook_catalog.py -q -p no:cacheprovider --basetemp=outputs/pytest-english-check
```

该测试覆盖示例逐项顺序、策略排除、空栏目处理、跨 Workbook 页码、共页阅读开头、历史记录保留、重复导入及学生接口权限。前端使用 `npm run build` 检查类型与构建。
