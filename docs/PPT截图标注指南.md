## 四、截图操作建议

### 4.1 准备工作

1. **准备测试数据**：至少创建 3-5 个学生账号，每个学生有 2-3 次提交记录（含教案和视频），确保有 AI 分析结果
2. **确保 AI 服务可用**：检查 API Key 配置正常，AI 分析功能可正常运行
3. **浏览器设置**：
   - 使用 Chrome 浏览器
   - 分辨率设为 1920x1080
   - 缩放比例 100%
   - 关闭浏览器插件（避免干扰界面）

### 4.2 截图技巧

- **Windows 截图工具**：`Win + Shift + S`（矩形截图）
- **Chrome DevTools**：`Ctrl+Shift+I` → `Ctrl+Shift+P` → 输入 "screenshot" → 选择 "Capture full size screenshot"（可截取整页长图）
- **建议格式**：PNG（清晰度更高），PPT 中可适当压缩

### 4.3 标注工具推荐

- **PPT 自带**：插入形状 → 矩形/圆角矩形框 → 设为无填充+红色边框 → 添加文字标注
- **Snipaste**：免费截图+标注工具
- **Draw.io**：在线标注工具

### 4.4 PPT 排版建议

| 排版方式 | 适用场景 | 说明 |
|----------|----------|------|
| 单图全页 | 数据大屏、雷达图 | 一张截图占满整个 PPT 页面 |
| 左图右文 | 功能介绍页 | 左侧截图，右侧 3-4 个要点 |
| 双图对比 | 传统 vs AI | 上下或左右对比 |
| 三图并排 | 三端功能展示 | 学生端/教师端/管理员端各一张缩略图 |
| 局部放大 | 细节展示 | 整图+放大框突出关键区域 |
